# Chauhan Aditya Ganpatbhai — Full-Stack Developer Portfolio

An editorial, brutalist, high-performance portfolio website engineered for **Chauhan Aditya Ganpatbhai**, inspired by the visual language, typography, and 3D WebGL interactions of [undefined-shin.com](https://www.undefined-shin.com/#/MainScreen).

Built with **React 19**, **Three.js (GLSL Shaders & 3D Earth Globe)**, **Vite 6**, and **Tailwind CSS 4**.

---

## ⚡ Key Highlights & Features

1. **Aesthetic & Visual Identity (Inspired by `undefined-shin.com`)**:
   - **Split Curtain Reveal**: Dual top & bottom split black curtain transitions on entry and route changes.
   - **Hero Editorial Typography**: Signature uppercase extended brutalist typography using genuine `HelveticaNeueLTStd-BdEx` OpenType font with `mix-blend-mode: difference`.
   - **Interactive 3D WebGL Mesh**: Morphing icosahedron crystal wireframe rendered in GLSL shaders with barycentric coordinates, procedural noise, and mouse inertia physics.
   - **3D Card Perspective Tilt**: Interactive card hovering with mouse-tracking `rotateX`, `rotateY`, and `translateZ` physics across projects.
   - **Interactive 3D Earth Globe**: Ultra-resolution 8K planetary surface with atmosphere glow shaders and interactive city markers (Surat, London, New York, Dubai, Tokyo).

## 🛠️ How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
